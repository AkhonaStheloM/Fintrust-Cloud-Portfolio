# Week 1: Cloud and SQL Foundations

## Overview

Week 1 introduced the foundations of Cloud Computing and SQL Databases. Throughout the programme, the learning is based on a single evolving case study: FinTrust Bank, a South African digital bank modernising its systems by moving from on-premises infrastructure to AWS.

As the programme progresses, each topic will contribute to designing and building FinTrust's cloud-native transaction intelligence platform.

## Cloud Computing Fundamentals

Topics covered included:

- Introduction to cloud computing
- Benefits of cloud adoption
- Cloud service models
- AWS Global Infrastructure
- AWS Regions
- Availability Zones (AZs)
- Edge Locations
- Shared Responsibility Model

## SQL Database Foundations

Topics covered included:

- Installing and configuring MySQL Workbench
- Database fundamentals
- Creating tables
- Inserting data
- Building the FinTrust database schema
- Understanding primary and foreign keys
- Writing basic SELECT queries
- Retrieving and sorting data

## Reflection

This week, I worked on the FinTrust data model and made my first set of architecture decisions. Understanding the relationships between customers, accounts, and transactions made the SQL exercises easier to follow because each foreign key represented a real banking relationship.

This week established the basic cloud and database knowledge needed for the later FinTrust practical work.
