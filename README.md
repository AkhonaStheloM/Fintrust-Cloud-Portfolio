# AWS Cloud Solutions Architect Learning Portfolio

> Preparing for the AWS Certified Solutions Architect – Associate certification.

## 1. My Career Direction: Cloud Solutions Architect

### What the role does
A Cloud Solutions Architect designs and guides cloud solutions that meet both business and technical requirements.

The role includes:

- Designing cloud architectures using services for compute, storage, databases, networking, and security.
- Building scalable, highly available, and fault-tolerant solutions.
- Configuring VPCs, subnets, routing, IAM, and security controls.
- Supporting application and infrastructure migrations to AWS.
- Improving performance, reliability, security, and cost efficiency through monitoring and optimisation.
- Creating architecture diagrams and technical documentation.
- Working with development, operations, security, and business teams.
- Using automation, Infrastructure as Code, and DevOps practices to improve cloud deployments.

## 2. Client Brief: FinTrust Bank SA

FinTrust Bank SA is a South African digital bank serving approximately 2.3 million customers across all nine provinces. Its systems currently run on on-premises servers located in two data centres: one in Johannesburg and one in Cape Town.

The bank is under pressure from several areas:

- Rapid customer growth, with a target of reaching 5 million customers by 2027.
- Increasing on-premises capacity limitations as the customer base grows.
- POPIA compliance requirements, including data residency and access logging.
- Increasing card fraud, creating a need for real-time transaction monitoring.
- Transaction latency of between 3 and 5 seconds during peak periods, which is unacceptable for a modern digital banking service.

### The assignment

My assignment is to design and progressively build a cloud-native transaction intelligence system for FinTrust Bank SA using AWS.

Each stage of the programme adds another layer to the solution, including compute, storage, databases, networking, security, analytics, cost management, migration, and governance. By the end of the practice journey, I will have developed a complete understanding of the proposed architecture.

The solution must help FinTrust:

- Scale as the number of customers increases.
- Monitor transactions and identify potential fraud more quickly.
- Reduce transaction latency during peak periods.
- Protect customer and transaction data.
- Support POPIA compliance and access auditing.
- Improve reliability while managing cloud costs responsibly.
